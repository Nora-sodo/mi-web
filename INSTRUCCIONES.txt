LIFEPLAN — ENGLISH DEFAULT + GOOGLE / PASSWORD LOGIN + DEMO CONTENT

1. Guarda una copia de seguridad de los datos y del repositorio GitHub.
2. Sustituye index.html y los iconos lifeplan-icon-*.png en el repositorio (mantén CNAME y .nojekyll).
3. Configura Supabase > Authentication > Providers > Email:
   - activa Email, y permite contraseña (password-based authentication).
   - si la confirmación de email está activada, los nuevos registros deben confirmar el correo.
4. Supabase > Authentication > Providers > Google:
   - activa Google y añade el Client ID/Client Secret de Google Cloud OAuth.
   - la URI de redirección autorizada en Google Cloud es la callback que Supabase proporciona: https://TU-PROYECTO.supabase.co/auth/v1/callback
5. Supabase > Authentication > URL Configuration: Site URL https://dosonoprojects.top/ y Redirect URLs https://dosonoprojects.top/** (según configuración de tu Supabase).
6. Prueba el registro por contraseña en una ventana privada, luego login y Google; confirma conservación de sesión y logout.
7. Inglés es el idioma predeterminado para nuevos visitantes. Preferencias anteriores de idioma se respetan: cambia manualmente el idioma si ya lo habías seleccionado.
8. En Explorar encontrarás rutas y proyectos de ejemplo, identificados como Demo. Puedes usar sus plantillas; no se han creado cuentas falsas en Supabase Auth ni puntuaciones falsas en el ranking real.

Nota: Supabase puede requerir correo confirmado. El enlace de recuperación abre un formulario para definir nueva contraseña mediante updateUser; comprueba este flujo real antes de producción. Cuentas creadas anteriormente por enlace mágico pueden usar «Forgot your password?» para establecer contraseña.
No ejecutes SQL ni compartas secretos de Google o Supabase en el chat.
